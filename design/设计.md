# 首页（Workspace）视觉升级设计

> 样图：[`首页样图.html`](./首页样图.html)（独立可预览，浅/深主题均可切换，复用项目真实 CSS 变量）
> 风格方向：**柔性卡片 / 新拟态（Soft Neumorphism）**
> 目标：**分区更分明、整体更立体、样式更活泼**，同时保留现有紫/蓝/青品牌色与亮/暗双主题。

---

## 1. 设计目标

对比现有 UI，本次升级聚焦三点（不改布局结构与功能）：

| 诉求 | 落地手段 |
|---|---|
| **区域之间风格明显** | 每个区域使用独立的「表面处理」——浮起 / 下沉 / 不同底色，靠光影而非线框分区。 |
| **整体更立体** | 多层柔和阴影（外发光提升 + 内高光），区域用渐变底色而非纯色平铺。 |
| **样式更活泼** | 圆润「鹅卵石」形状、悬浮上浮 / 按压回弹动效、彩色圆形标签与渐变描边。 |

---

## 2. 四个区域与表面层次

界面被明确划分为四个区，**通过"浮起 / 下沉"的对立关系一眼区分**：

### 区域 1 · 品牌区（左上品牌卡）— 浮起
- 在带品牌色渐变（`--brand-card-from/to`）的底面上做**明显浮起卡片**：外阴影 + 顶部内高光（`--neu-raise`）。
- Logo 使用现有 conic 渐变并加发光环，像产品「控制台」标头，明显脱离侧栏。
- 账号信息 + 「新会话」主按钮（胶囊 + 强渐变 + 发光 `--neu-pop`）同处一行。

### 区域 2 · 会话列表（侧栏列表）— 下沉容器 + 浮起条目
- **侧栏整体作为下沉容器**（`--neu-sink` 内阴影），与上方浮起的品牌卡形成即时的区域对立。
- 每条会话是**浮起的"鹅卵石" pill**（圆角 14px + `--neu-raise-sm`）；hover 上浮 2px。
- 选中态：accent 渐变描边 + 左侧渐变指示条 + 加强阴影（`--neu-pop`）。
- Agent 类型用活泼的彩色圆角 chip（沿用 `--tag-*` token）。

### 区域 3 · 聊天主区 — 最亮、最开阔
- 独立的浅色开阔表面，背景叠加一层极淡的品牌色径向光晕（`--zone-chat-bg`），与侧栏底色明显不同。
- 消息气泡变为**悬浮卡片**：助手气泡 = 中性浮起卡（`--neu-raise`），用户气泡 = accent 微染浮起（`--neu-raise-sm`）；圆角加大（`--radius-lg`），并带入场上浮动画。
- 生成结果以渐变小卡（`--gen-card-*` 风格）内嵌展示。

### 区域 4 · Agent 切换器 + 输入区 — 底部浮起面板
- 切换器为**胶囊分段控件**：轨道下沉（`--neu-sink`），激活项为浮起「滑块」并在点按时回弹。
- 输入框为醒目的**浮起胶囊**，聚焦时 accent 发光描边（focus glow）。

## 3. 新增设计 token（立体阴影）

现有调色板已足够；只需补充一组「新拟态」阴影 token，亮/暗各一份，**全部经由 `var(--*)` 引用，不写死 hex/rgba**，保证暗色模式不破。建议加入 `web/src/App.css` 的 `:root` 与 `[data-theme="dark"]`：

```css
/* :root（浅色） */
--neu-raise:    0 6px 16px rgba(31,33,58,0.10), 0 1px 0 rgba(255,255,255,0.9) inset, 0 -2px 6px rgba(255,255,255,0.6) inset;
--neu-raise-sm: 0 3px 8px  rgba(31,33,58,0.10), 0 1px 0 rgba(255,255,255,0.8) inset;
--neu-sink:     inset 0 2px 6px rgba(31,33,58,0.10), inset 0 -1px 0 rgba(255,255,255,0.6);
--neu-pop:      0 10px 24px rgba(109,92,240,0.22), 0 1px 0 rgba(255,255,255,0.4) inset;
--zone-sidebar-bg: linear-gradient(180deg, #edecf6, #e6e6f0);
--zone-chat-bg:    radial-gradient(120% 80% at 70% -10%, rgba(139,92,246,0.08), transparent 60%), var(--bg);

/* [data-theme="dark"] */
--neu-raise:    0 8px 22px rgba(0,0,0,0.45), 0 1px 0 rgba(255,255,255,0.05) inset, 0 -2px 6px rgba(0,0,0,0.3) inset;
--neu-raise-sm: 0 4px 12px rgba(0,0,0,0.4),  0 1px 0 rgba(255,255,255,0.04) inset;
--neu-sink:     inset 0 2px 8px rgba(0,0,0,0.5), inset 0 -1px 0 rgba(255,255,255,0.03);
--neu-pop:      0 10px 26px rgba(34,211,238,0.28), 0 1px 0 rgba(255,255,255,0.06) inset;
--zone-sidebar-bg: linear-gradient(180deg, #131318, #0e0e12);
--zone-chat-bg:    radial-gradient(120% 80% at 70% -10%, rgba(34,211,238,0.08), transparent 60%), var(--bg);
```

## 4. 活泼感动效清单

| 元素 | 交互 |
|---|---|
| 会话条目 | hover `translateY(-2px)` + 阴影加强 |
| 主按钮 / 发送钮 | `:active` 按压回弹（scale 0.92–0.98） |
| 切换器激活项 | 切换时滑块浮起 + 轻微回弹 |
| 输入胶囊 | focus 时 accent 发光描边 |
| 消息气泡 | 入场 `rise` 上浮淡入 0.35s |

动效均短促（≤0.35s）、克制，符合现有产品调性。
