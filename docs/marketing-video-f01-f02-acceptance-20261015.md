## F01：素材访问

新营销上传带 `purpose=marketing-video`。服务端写入 `assets.is_private=true`。缺少签名密钥时，接口在写文件前返回 503。其他模块的普通上传保留原行为。

迁移 `0047-marketing-private-materials.ts` 扫描项目草稿和营销父任务的冻结草稿。它覆盖单个 ID、ID 数组和大写 UUID。它只保护归属一致的上传资产。它不修改素材 ID、永久地址或冻结输入。之后在营销草稿中使用普通上传时，也会将该上传转为私有。移除素材不会恢复公开访问。

| 请求 | 预期 | 实测 |
| --- | --- | --- |
| 无登录、无临时令牌，读取私有素材 | 拒绝 | HTTP 404 |
| 使用另一用户的会话 | 拒绝 | HTTP 404 |
| 使用所有者会话 | 允许 | HTTP 200 |
| 使用有效临时链接读取指定字节 | 允许 | HTTP 206，正确 Content-Range |
| 令牌过期、被篡改、用途不符或密钥不符 | 拒绝 | HTTP 404 |
| 素材已删除、归属改变、数据库查询失败 | 拒绝 | HTTP 404 |
| 文件存在，但没有资产记录 | 拒绝 | HTTP 404 |

临时链接有效期为 10 分钟。令牌绑定素材 ID、所有者和存储键。响应使用 `private, no-store`。浏览器预览失败时，通过所有者资产接口重新取链接。重取链接不保存草稿，也不调用模型。重复重取限制为每素材每分钟一次。

Worker 在新提交前验证本地素材归属。图片编辑的本地读取也执行该检查。供应商只收到短期链接。图片和视频链接在音色准备结束后重新签发。临时令牌不写入任务输入、缓存身份或音色指纹。

通用生成日志不再记录请求正文和响应正文。供应商错误移除精确提示词、链接和凭证。Hono 跳过素材路径日志。Nginx 的 `/static/uploads/` 单独关闭访问日志、错误日志和代理缓存。

范围说明：生成成片、生成图片和显式分享未改为私有。历史上传若已从所有草稿和冻结任务中移除，现有数据无法证明其营销用途。本次不能自动识别这类孤立历史素材。已被外部保存的旧副本也无法撤回。

## F02：队列隔离

```text
营销父任务 ── lot-marketing-video ── 营销 Worker（并发 1）
                                     └─ 片段并发最多 2
普通任务   ── lot-tasks ─────────── 普通 Worker（并发 1）
旧营销作业 ── lot-tasks ── 转发原任务 ID ── 营销专队列
```

两个 Worker 由现有普通 Worker 进程启动。该设计隔离消费槽位。它没有新增部署进程。FFmpeg 和普通任务仍共享主机资源。

迁移 `0046-marketing-video-queue.ts` 只更新营销父任务的 `queue_name`。新父任务直接记录专队列名称。片段任务仍由原父任务编排。旧共享队列中的 active 作业不重复投递。等待作业保留原任务 ID 迁移。锁竞争时停止迁移。旧队列转发不会自动重跑终态作业。

取消检查两个队列。显式恢复也检查两个队列。原 Worker 收尾期间不得恢复。未启动任务的超时保护覆盖两个队列。

## 升级和发布验收

1. 停止新任务提交。
2. 等待使用旧无签名素材地址的供应商任务完成。
3. 停止旧版本 Worker。
4. 备份业务数据库。
5. 为 API 和 Worker 配置同一个现有 `SECRET_MASTER_KEY`。不要随意更换已用于加密数据的密钥。
6. 核对 `PUBLIC_BASE_URL`。
7. 启动新 API，执行迁移至 47。
8. 同步启用新版 Worker、Web 和 Nginx 配置。
9. 验证生产网关拒绝无令牌的私有素材请求。
10. 验证真实供应商在链接有效期内完成取材。
11. 验证原任务继续查询，计量没有重复记录。
12. 恢复新任务提交。

发布前还需在目标环境执行 `nginx -t`。还需检查外层 CDN / 网关不缓存素材、不记录查询令牌。旧代码不能在迁移后混跑；旧静态路由会重新暴露文件。任务正在供应商端排队时，旧裸链接失效可能导致取材失败，因此应先完成第 2 步。

本轮不证明生产 P95 延迟、资源隔离或生成音画质量达标。F03 及其他评审项不在本次修复范围。
