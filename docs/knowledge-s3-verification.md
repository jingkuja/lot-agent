## 已实现

- 迁移 29：知识访问密钥、按库授权、用量归属字段及旧库映射。密钥高熵生成、只存哈希；可编辑授权、过期、轮换、撤销，版本控制和每次重新鉴权。
- `/api/rag/v1` 列库、检索、白名单资料元数据、原件 GET/HEAD/Range、共享个人信息精确读取。独立知识密钥认证，不能以登录令牌、请求 owner 或 userId 替代。Redis 60 次/分钟、5 并发及 60 秒期限；流式响应结束后释放并发槽。
- 调用采用所有者的 TokenHub 凭证，查询用量记录知识密钥和应用名。额度不足返回 402；降级必须显式允许。查询限制 2000 Unicode 字符，实际向量调用后再检查 2048 token 上限；这次调用仍按真实用量记账。
- Lot Agent 配置默认切换到 local；内部直接调用 KnowledgeService。历史无来源引用按 remote 处理，需按 owner 映射或重新选库；不做远端回退。
- 聊天的完整版本证据和定位经 SSE 传递并随最终回复存储；出处组件读取前重新鉴权及检查当前版本，删除后不再打开旧原文。选库弹窗可打开内置管理视图。
- “外部接入”页面：显式库/权限/到期选择，一次性密钥、编辑、轮换、撤销、最近使用和环境变量示例。调用示例不含实际密钥；调试检索仍使用现有会话接口。
- [标准接口说明](knowledge-external-api.md)、[OpenAPI 3.1](knowledge-openapi.json)，AJV 契约边界与真实 HTTP 响应校验。
