6 技术路线与风险 结构合理，质量路线有风险

合理的部分

  • 前后端共用 core 里的 schema 和规则；视频模型的限制写在 MarketingVideoProfile 中，冻结任务按原模型恢复。
  • PG 是唯一数据来源，BullMQ 只负责投递；营销视频使用独立队列，按用户公平调度。
  • 付费保护完整：请求幂等，回执先于结果保存；结果未知时不自动重发，用户确认"可能重复计费"后才能放弃或重提，并留记录；网关没有返回结果时按未扣费处理并保存网关请求 ID，供退费核对；计量带幂等键，复用的片段不再计量。
  • 素材检查、FFmpeg 和字幕能力、配音文件都在付费调用前检查；上传素材使用私有签名链接，日志只记标识。
  • 没有引入通用 DAG 或多 Agent 编排。marketing_video Agent 工具白名单为空，由项目 API 控制制作，当前不需要编排框架。
