## 部署与兼容

先运行迁移 42（文本操作）和 43（清理标记），再更新 API/Web/媒体 Worker。旧 `/copy` 和分镜客户端缺少请求 ID 时拒绝调用。旧草稿 JSONB 不重写，已有视频任务 ID、时长与计量不改变。回退代码不需要删除新表，不能回退到不持久化的付费创作入口后仍宣称具有相同恢复保证。

本次没有改变 frames-v1 提示词，输入限制保持首次顺序，以兼容现有回执。更早提示词版本的旧记录如触发 `MODEL_INPUT_CHANGED`，继续拒绝重发；应使用对应历史代码恢复或人工核对回执，不修改哈希或删账本。缺少视觉完成字段的旧任务从持久化批次回执读取状态。

文本操作的 unknown 不自动重放，也不提供一键清除。管理员需结合响应 ID 和上游真实回执核对；缺失回执不等于未收费。持久化创作请求通过 onAttempt 阻止 Chat Completions 提供器的底层自动重发；模型调用前的授权失败记录为 rejected，不锁死草稿。已经提交成功的结果可以跨实例查询；完整模型回执之后、结果事务提交之前的进程中断仍需核对保存的原始回执。结果检查和核对不调用模型。

累计存储默认每用户 2 GiB、全局磁盘至少保留 1 GiB，并按每在途任务 512 MiB 保守预留。配置见 `.env.example` 的 `MARKETING_ANALYSIS_OWNER_BYTES` / `MARKETING_ANALYSIS_MIN_FREE_BYTES`。文件保留清单是 snapshot.frames 与 selection 的并集；不删除现有可展示帧，因此不需要改变其可见性或修改旧模型输入。任务外程序仍可能占用共享磁盘，生产容量告警与卷隔离仍需运维验收。
